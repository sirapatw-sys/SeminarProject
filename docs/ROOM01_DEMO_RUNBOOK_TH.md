# คู่มือผู้สาธิต Room01
สถานะ: เส้นทางสาธิตและ checklist สำหรับคน พร้อมแยกจาก playtest แบบไม่บอกคำตอบ
อ้างอิงข้อมูล Room01_Companion/Room01_Reasoning ปัจจุบัน ใช้เดโม offline; ยังไม่ใช่หลักฐานว่าเล่นด้วยคนผ่านแล้ว

## เตรียม
เปิด MysteryGame.exe จาก build ที่บันทึกไว้ เลือก New Game ทดสอบทั้งการพิมพ์และการปิดคุยก่อนเริ่ม
เก็บ commit/build ID กับคลิปที่ใช้จริง; หาก build/ข้อมูลเปลี่ยนให้บันทึกใหม่
ไม่ใช้เส้นทางนี้สอนผู้เล่น pilot ก่อนทดลอง เพราะจะทำให้วัดการค้นพบความสามารถเองไม่ได้

## เส้นทางความร่วมมือ
1. สำรวจภาพวาดด้วยผู้เล่น ชวน Alice มาใกล้แล้วคุย เพื่อแยกสิ่งที่ผู้เล่นรู้กับสิ่งที่เธอเห็น
2. ขอ “ช่วยจับให้หน่อย” ในจุดที่ยังไม่มีสถานีเดียวใกล้ชัดเจน; เมื่อถามกลับตอบ “ขอบโต๊ะ”
3. ปิดคุย รอเธอเดินถึงโต๊ะ แสดงสถานะกำลังไปช่วย/จับไว้ให้แล้ว ผู้เล่นไปอีกฝั่งและสำรวจจริง
4. อ่านโน้ตที่ผู้เล่นได้ ขอค้นทั้งห้องด้วย “ช่วยค้นห้องหน่อย” แล้วปิดคุยให้เดินสำรวจ
5. เมื่อมีสัญญาณรายงาน ค่อยเข้าไปคุย/ถาม “เธอเจออะไรบ้าง”; รายงานได้เฉพาะข้อมูลที่เธอรู้และอนุญาต
6. แบ่งปันหลักฐานที่ผู้เล่นพบผ่านเส้นทาง evidence sharing เดิม ตรวจว่า NPC รู้ desk_note และ note_direction ครบก่อนประเมิน
7. พิมพ์ “เราคิดว่าอ่านจากขวาไปซ้าย” ให้เธอประเมิน จากนั้นผู้เล่นเป็นคนลองรหัสด้วยตนเอง
8. ถ้า NPC อยู่ใกล้และเห็นการลองไม่สำเร็จจริง ปิด keypad แล้วเธอจะส่ง ! ชวนทบทวน (ตามลำดับ story events เดิม) ผู้เล่นค่อยกดคุย ไม่มี choice บังคับ; พิมพ์ “ยังเปิดไม่ออกเลย” เพื่อดูคำตอบอ้างเหตุการณ์ หลังสำเร็จพิมพ์ “เราทำได้แล้ว”
9. จบ Room01 แล้วหยุด ก่อนเกมพาไปห้องถัดไป

ระดับความสัมพันธ์จาก New Game อาจให้คำตอบระมัดระวังตามกติกา อย่าอ้างว่าคำตอบละเอียดจะปรากฏเสมอ
หากเปรียบเทียบ trust ให้ใช้ fixture/test harness หรือเซฟสาธิตที่ตั้งและบันทึกไว้ ไม่ปรับคะแนนอย่างลับ ๆ กลางการเล่น
การอธิบายเส้นทางให้คนดูไม่แทนหลักฐานว่าผู้เล่นใหม่ค้นพบได้เอง

## ตรวจด้วยคนก่อนถ่ายคลิป
| จุดตรวจ | ผล / build / ผู้ตรวจ |
| --- | --- |
| เปิดเกม New Game และออกจากคุยหลังส่งข้อความ | รอทดลอง |
| ขอเดินตาม → หยุดเดิน → ไม่เดินต่อ | รอทดลอง |
| ขอค้น → เดินตามเส้นทาง → รายงานสิ่งที่พบ | รอทดลอง |
| ถามกลับ → ตอบชื่อ → เดินช่วยโต๊ะจริง | รอทดลอง |
| ท่าช่วย/ทิศหัน/จุดยืนแยก NPC กับผู้เล่นอ่านออก | รอทดลอง |
| กล่องสองมือคืบหน้าเมื่อทั้งคู่ยืนถูกและหยุดเมื่อออก | รอทดลอง |
| คำขอถูกปฏิเสธอธิบายได้ / ไม่ให้รางวัลก่อนสำเร็จ | รอทดลอง |
| ทดลองคำตอบผิด → NPC อ้างเฉพาะสิ่งที่เห็น | รอทดลอง |
| ตัวอักษรไทยอ่านได้ ไม่มีข้อความค้างบังการเล่น | รอทดลอง |
| เสียง/ภาพ/การชนที่ความละเอียดใช้จริง | รอทดลอง |
| เส้นทางเดี่ยวผ่านได้โดยไม่ต้องปั๊มความสัมพันธ์ | รอทดลอง |

## สิ่งที่พูดขณะเดโม
“ตอนนี้ผู้เล่นมีข้อมูลอีกส่วน Alice ต้องไปพบหรือรับข้อมูลก่อนจึงช่วยประเมินได้”
“เธอเริ่มช่วยเมื่อผู้เล่นขอ และการคุยไม่ได้ทำให้งานสำเร็จ ผู้เล่นยังต้องลงมือ”
“ต้นแบบนี้ใช้ออฟไลน์เพื่อพิสูจน์วงจรเกม ส่วนคุณภาพโมเดลจริงยังต้องประเมินแยก”

คลิปสำรองที่ควรเก็บ 60–90 วินาที: ขอช่วย/ถามกลับ 15s → ช่วยจริง 20s → แลกหลักฐาน/ร่วมคิด 25s → ผู้เล่นทดลอง/ตอบรับผล 15s
บันทึกว่าเป็น clip ที่ตัดจากการเล่นหรือ staged demo พร้อม build ID ไม่ใช้แทน playtest results
