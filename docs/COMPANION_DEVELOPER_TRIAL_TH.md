# ทดลองนำ Companion Reasoning ไปใช้ในเกมใหม่
สถานะ: ขั้นตอนและแบบบันทึกพร้อมใช้ ยังไม่มีผลจากผู้พัฒนาอื่น
ใช้กับ package com.mysterygame.companion-reasoning 0.2.0 / Unity 2021.3.16f1

## คำชี้แจงให้ผู้ทดลอง
คุณกำลังทดลองโมดูลร่วมคิดจากหลักฐาน เป้าหมายคือให้ตัวละครประเมินแนวคิดตามสิ่งที่รู้จริง และให้เกมควบคุมการลงมือ
จับเวลาตั้งแต่เปิดคู่มือ README ใน package บันทึกเวลาติดตั้ง sample สำเร็จ และเวลาสร้างเนื้อหาใหม่สำเร็จแยกกัน
ผู้จัดไม่บอกขั้นตอนล่วงหน้า ทุกครั้งที่ถามผู้จัดให้นับหนึ่งครั้ง ไม่เก็บชื่อจริง/credentials
เป้าหมายทดลอง 30 นาทีถึง sample และ 90 นาทีถึงเนื้อหาใหม่ เป็นเป้าหมายออกแบบ ยังไม่มีผลยืนยัน

## ภารกิจ
1. สร้าง Unity project เปล่า ติดตั้ง package จาก disk และ import Repair Workshop ตาม README
2. ทดสอบก่อน/หลังตรวจสายและสวิตช์ไฟ ถาม “maybe the cable is loose” คำตอบก่อนมีข้อมูลต้องต่างจากหลังมีข้อมูล
3. ทดลอง allowedDetail 1/2/3 โดยคงหลักฐานเหมือนกัน การคุยต้องไม่ซ่อมอุปกรณ์เอง
4. สร้างปริศนาต่างธีมหนึ่งแบบ เช่น ตู้ปลูกพืช: facts “ดินแห้ง” และ “ถังน้ำมีน้ำ”, hypothesis “อาจต้องรดน้ำ”
5. สร้าง profile ใหม่ เพิ่ม facts สองรายการใน host และ hypothesis หนึ่งรายการใน profile; เพิ่ม host action “water-plant” ผ่าน CompanionEffectRegistry
6. เปลี่ยน npcId/คำตอบ/ระดับรายละเอียดด้วยข้อมูล ไม่แก้ package core
7. ลองไม่มีหลักฐาน, ข้อมูลครบ, หลังงานเสร็จ, action ซ้ำ และไม่รู้จัก hypothesis; จดพฤติกรรมจริง

Repair Workshop เป็นตัวอย่างเฉพาะอุปกรณ์ซ่อม ไม่ได้แปลงเป็นตู้ปลูกพืชด้วยการเปลี่ยน profile อย่างเดียว เพราะ facts/interaction IDs ใน sample อยู่ฝั่ง host ต้องเขียน/ปรับ host สำหรับธีมใหม่ตาม INTEGRATION.md
ปุ่ม Inspect/Repair ใน sample เป็น interaction ของโลกเกม ไม่ใช่ตัวเลือกคำสั่งให้ NPC; ผู้เล่นพิมพ์สมมติฐานเอง
