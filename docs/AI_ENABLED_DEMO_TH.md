# เล่นเดโมรุ่นเปิด AI
ใช้กับ ZIP ที่ชื่อ MysteryGame-AI-Enabled เท่านั้น รุ่น MysteryGame-Offline ปิดการเชื่อม AI ไว้
รุ่นนี้เปิดการเรียก provider ตามการตั้งค่า ไม่ได้แถมคีย์หรือบัญชี AI

## เริ่มใช้
1. แตก ZIP ทั้งหมดลงโฟลเดอร์ใหม่ก่อน อย่าเปิด exe จากหน้าต่าง ZIP โดยตรง
2. เปิด MysteryGame.exe เลือกตั้งค่า หรือกด F10
3. ถ้าใช้ Gen AI KKU ให้เลือก KKU IntelSphere ระบบเติม endpoint ให้เอง
4. ใส่คีย์ของบัญชีคุณ เลือกโมเดลที่บัญชีมีสิทธิ์ใช้ หากรายชื่อเดิมไม่มี ให้โหลดรายชื่อล่าสุดหรือพิมพ์ model ID เองตามผู้ให้บริการ
5. กด “บันทึกและใช้งาน” ต้องเห็น “บันทึกแล้ว” ขั้นนี้ยังไม่ส่ง API request
6. กด “ทดสอบการเชื่อมต่อ” เมื่อขึ้น “เชื่อมต่อสำเร็จ” ให้ปิดตั้งค่าแล้วเริ่ม/เล่นเกมต่อได้ การทดสอบและบทคุย AI ใช้โควตาของบัญชีคุณ
7. ลองพิมพ์บทคุยทั่วไปกับ NPC เช่น “ตอนนี้เธอรู้สึกยังไงบ้าง” คำสั่งเดิน/หยุด/ช่วยบางงานใช้บทที่เกมกำหนดให้ตรงกับผลการกระทำ จึงอาจตอบเหมือนเดิมแม้ AI เปิดอยู่

โมเดลและ endpoint บันทึกข้ามการเปิดเกม คีย์ที่พิมพ์ใช้เฉพาะรอบนี้ ปิดเกมแล้วใส่ใหม่
หากอยากให้ KKU โหลดคีย์จากเครื่องทุกครั้ง สร้างโฟลเดอร์ UserSettings ข้าง MysteryGame.exe แล้วสร้าง kku_api_key.txt ภายใน ใส่เฉพาะคีย์ด้วยตัวเอง ไฟล์นี้เป็นความลับของคุณ อย่าแนบมากับ ZIP ที่ส่งต่อ
ไม่ต้องส่งคีย์ให้ผู้พัฒนาหรือวางในแชท

## อ่านผลให้ถูก
- “บันทึกแล้ว”: เก็บค่าแล้ว ยังไม่ยืนยันว่าผู้ให้บริการรับคีย์/โมเดลนี้
- “เชื่อมต่อสำเร็จ”: คำขอทดสอบได้รับคำตอบที่ระบบอ่านได้
- ข้อความว่าเดโมออฟไลน์: เปิดผิดรุ่น ให้ใช้ ZIP AI-Enabled
- HTTP 401: ผู้ให้บริการไม่รับการยืนยันตัวตน ตรวจคีย์และ provider ที่เลือก
- โมเดลไม่มีสิทธิ์/ไม่พบ: ใช้ model ID ที่บัญชีนี้มีสิทธิ์เข้าถึง
- รอเกินเวลาหรือรูปแบบตอบไม่ผ่าน: เกมอาจใช้บทสำรอง ดูข้อความจากการทดสอบประกอบ

## ขอบเขตที่ตรวจแล้ว
ชุดทดสอบอัตโนมัติใช้ provider จำลอง ไม่มีการยิงบัญชีจริงเพื่อยืนยัน model/key ของผู้เล่น
Windows build สำเร็จเป็นหลักฐานการคอมไพล์/จัดแพ็กเกจ ยังไม่ใช่ผลคุณภาพจากโมเดลจริงหรือ manual visual QA
รุ่นเปิด AI ไม่บังคับ offline provider และไม่เริ่ม playtest trace อัตโนมัติ; บทพูดและผล action ยังผ่านนโยบายหลักฐาน/คำใบ้ของเกม
ยังเก็บเดโมออฟไลน์เดิมไว้สำหรับทดลอง flow โดยไม่ใช้โควตา
