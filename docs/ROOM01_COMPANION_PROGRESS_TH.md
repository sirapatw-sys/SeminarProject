## 3. ฟีเจอร์ที่เราเพิ่มจริง

### Alice เดินสำรวจไปกับผู้เล่น

เข้าคุยแล้วพิมพ์ “ตามเรามาหน่อย” / “เดินไปด้วยกันไหม” ปิดบทสนทนาแล้ว Alice จะเดินตามด้วยเส้นทางที่ตรวจสิ่งกีดขวางและระยะหยุด ไม่เทเลพอร์ต พิมพ์ “รอตรงนี้ก่อน” เพื่อให้หยุดรอ ไม่มีปุ่มคำสั่งให้กดแทนการพูด และเอาแผงข้อความสอนเล่นที่ค้างมุมขวาออกแล้ว

ระบบรองรับคำชวนไทย/อังกฤษแบบจำกัด 4 กลุ่ม: เดินตาม รอ ช่วยกิจกรรมที่ระบุชื่อ และให้กำลังใจ คำถามวิธี คำถามสถานะ คำปฏิเสธ คำพูดอ้างอิง และข้อความสมมติไม่ใช่คำสั่ง หากขอหลายอย่างขัดกันจะขอให้ชวนทีละอย่าง

### กล่องสองมือ: กิจกรรมร่วมมือแบบเลือกเล่น

พิมพ์ชวนเปิด **กล่องสองมือ** ใกล้กิจกรรม แล้ว Alice ไปจุดสีฟ้า ผู้เล่นไปจุดสีทอง ยืนพร้อมกันครบ 3 วินาทีจึงสำเร็จ มีความคืบหน้าและภาพกล่องเปิด รางวัลความสัมพันธ์ +3 สมุดบันทึก และความทรงจำร่วม ได้ครั้งเดียวต่อเซฟ

กิจกรรมนี้ไม่แจกกุญแจหรือรหัส และไม่เป็นเงื่อนไขผ่านด่าน เส้นทางเดิมยังเป็น **ภาพวาด → โต๊ะ/โน้ต → ลิ้นชัก → กุญแจ → ประตู** วิธีเล่นกิจกรรมเป็นข้อมูลคนละส่วนกับคำใบ้ปริศนาหลัก ไม่เพิ่มสิทธิ์คำใบ้ตามความสัมพันธ์

### ปฏิกิริยาต่อสิ่งที่ผู้เล่นทำจริง

เมื่อ Alice อยู่ใกล้ เธอมีข้อความสั้น ๆ ต่อการสำรวจภาพวาด โต๊ะ หรือการเปิดลิ้นชักสำเร็จ/ไม่สำเร็จ พร้อมความทรงจำ เหตุการณ์ไม่เด้งเปิดบทสนทนาเพื่อหยุดการเล่น และแต่ละปฏิกิริยาเกิดครั้งเดียวต่อเซฟ

ปรับสัญญาณผลการกระทำให้แม่นขึ้น: ใส่รหัสครบแต่ผิดนับเป็นความพยายามที่ล้มเหลวจริง การใส่ไม่ครบหรือกดปิดไม่ถือว่าล้มเหลว และตรวจลิ้นชักที่เปิดแล้วไม่ถูกจำว่าเปิดไม่สำเร็จ

### ให้กำลังใจและจำประสบการณ์ร่วม

พิมพ์ “ไม่ต้องกลัวนะ เราอยู่ด้วย” แล้วเกิดความทรงจำ ลดคิดถึงบ้าน 10 และความสัมพันธ์ +1 ครั้งเดียวต่อเซฟ การพูดซ้ำไม่ใช้ปั๊มรางวัล บททักและบริบทสนทนาสามารถอ้างถึงสิ่งที่เคยทำร่วมกันได้ตามเงื่อนไขเดิม

### AI รับรู้ Companion แต่ไม่เป็นผู้ควบคุมเกม

เพิ่มข้อเท็จจริงกิจกรรม `pending` / `completed` / คำแนะนำ / ยังไม่พร้อม และโหมดเดินตาม–รอ–ช่วยจากตัว NPC จริง AI อ้างผ่าน `{fact:id}` แยกบรรทัด แล้วเกมเติมข้อความที่ยืนยันได้ ห้ามให้ข้อความผู้เล่นหรือคำตอบ AI ทำให้กล่องเปิดเอง

คำชวนที่รองรับดำเนินการผ่านเส้นทางผู้เล่นส่งข้อความโดยตรง ไม่เรียก provider เพื่อสั่งงาน จึงเดโมระบบนี้ได้โดยไม่ใส่ API key ส่วนบทคุยทั่วไปยังใช้ provider เดิมได้ ตัวกรองตรวจทั้งแชทและ mini-event และยังรักษาระดับคำใบ้ตามความสัมพันธ์เดิม

### โครงสร้างที่นำไปต่อยอดได้

- `CompanionScenarioData` / `CompanionStationData` เก็บ NPC ขอบเขตเดิน ระยะ ความเร็ว จุดยืน เวลา เงื่อนไข ชื่อเรียกกิจกรรม บทพูด และความทรงจำ
- `RoomKnowledgeData.companionScenario` เลือกเปิดใช้เป็นรายห้อง ไม่เปิดใน Room02–03 อัตโนมัติ
- `NpcCompanionController` ดูแลการกระทำและผลจริง, `CompanionNavigator` หาเส้นทาง, `CompanionDialogueCommands` แยกคำชวน และ `CompanionHud` แสดงสถานะ/กิจกรรม
- `InteractionSignals` ส่งผลสำรวจจริง และ Content Validator ตรวจข้อมูลกิจกรรม

ตัวอย่างข้อมูลคือ `Assets/Data/Companions/Room01_Companion.asset` ปรับกิจกรรมสองฝ่ายลักษณะเดียวกันผ่าน Inspector ได้ แต่กลไกใหม่คนละประเภท เช่น หยิบสิ่งของหรือยกย้ายเฟอร์นิเจอร์ ยังต้องเพิ่มระบบ ไม่ใช่เปลี่ยนข้อมูลแล้วทำได้ทุกอย่าง

### กติกาป้องกันผลข้างเคียง

ตรวจ NPC ห้อง ระยะ และเงื่อนไขก่อนรับคำชวน ไม่สั่งข้ามหน้าต่างอื่น ระหว่างคุย/เมนู/สมุด/คีย์แพด/หน้าต่างไอเทม/ตั้งค่าจะพักการเดินและงาน ไปไม่ถึงหรือเกิน 45 วินาทีของเวลาเล่นจริงจะยกเลิกโดยไม่ให้รางวัล ชวนงานเดิมซ้ำไม่ล้างความคืบหน้าหรือต่อเวลา

เซฟเก็บผลสำเร็จ สมุด และความทรงจำ ไม่เก็บเส้นทางเดินหรืองานค้าง โหลดแล้วต้องชวนใหม่ กรณีเคยเดินตามก่อนช่วยงานยังกลับไปเดินตามได้ ส่วนคำชวนให้รอหยุดงานและเลิกตาม

## 4. แก้ 4 จุดจากการตรวจรอบล่าสุดแล้ว

1. **คำลงท้ายเปลี่ยนเจตนาแต่ระบบเคยลงมือไปก่อน:** “เธอตามเรามา, ใช่ไหม” ไม่เริ่มเดิน; “ช่วยเปิดกล่องสองมือ, ไม่เอาแล้ว” ไม่เริ่มงาน รวบรวมคำขอและอ่านคำลงท้ายให้จบก่อนตัดสิน ยังรับคำชวนใหม่หลังถอนคำขอได้ การถอนนี้ครอบคลุมคำขอในข้อความเดียวกัน ไม่ใช่ยกเลิกงานที่รับไปแล้วจากข้อความก่อนหน้า
2. **คำอ้างสำเร็จที่ละชื่อสิ่งของ:** “งานเสร็จแล้วค่ะ”, “ตอนนี้เสร็จแล้วค่ะ”, “ฉันช่วยแก้ให้เสร็จแล้ว” ต้องมีหลักฐานเช่นเดียวกับคำอ้างเปิดกล่องตรง ๆ ตรวจคำตอบหลังเลือกตัวเลือกด้วย และไม่ให้ fact ที่ถูกต้องรับรองข้อความแต่งเพิ่ม
3. **อัญประกาศกับ Unicode ตรวจคนละรูป:** ตรวจอัญประกาศหลัง normalize เช่น `＇ตามเรามา＇` และคำพูดอ้างอิงที่มีอักขระซ่อนต่อท้ายไม่กลายเป็นคำสั่ง
4. **บทคุยสังคมภาษาอังกฤษโดนตัดเกินจำเป็น:** อนุญาต “We're done talking for today.” / “I'm holding back tears.” เฉพาะส่วนความหมายทางสังคม แต่ยังปฏิเสธคำอ้างผลกิจกรรม รหัส และข้อมูลที่ไม่ได้รับสิทธิ์ในส่วนอื่นของข้อความ

เพิ่ม regression ถาวร `CompanionQualifierRegressionTests` และ `CompanionQualifierPlayTests` 72 กรณี รวมกรณีส่งข้อความผ่าน UI และตรวจสถานะ/ประวัติจริงด้วย provider จำลอง ไม่ใช่ทดสอบ regex อย่างเดียว

### ปรับภาพหน้าจอและจังหวะเดินเพิ่มเติม

- ไม่มีแผงข้อความค้างมุมขวา ชื่อกล่องขึ้นเมื่อผู้เล่นเข้าใกล้ 2.4 หน่วยเท่านั้น จุดสีเล็กไม่มีตัวอักษรและเปอร์เซ็นต์ขึ้นเฉพาะกิจกรรมที่กำลังช่วย เมื่อเปิดกล่องแล้วป้ายหาย แต่ภาพกล่องเปิดยังอยู่
- ความเร็ว Alice ลดจาก 4.4 เป็น 2.6 หน่วย/วินาที ค่อย ๆ เร่งและผ่อน ไม่ขยับเต็มความเร็วทันที ระยะเริ่มตามใหม่มากกว่าระยะหยุดเพื่อลดการขยับถี่ และการพักเมนู/หยุดรอล้างความเร็วค้าง
- ย่นมุมเส้นทางเฉพาะทางที่ตรวจชนแล้ว โดยตรวจทั้งเส้นลัดและก้าวจริง ถ้าก้าวลัดไม่ปลอดภัยใช้เส้นทางเดิมแทน ไม่ตัดเส้นทางเดิมทิ้งก่อนตรวจ
- ลดจังหวะเดิน/ความสูงเด้งและปรับตามความเร็วจริงเฉพาะ Companion ไม่เปลี่ยนการเดินของผู้เล่นหรือ NPC ห้องอื่น ค่าทั้งหมดปรับผ่าน scenario ใน Inspector ได้
- เพิ่ม `CompanionPresentationTests` / `CompanionPresentationPlayTests` ตรวจการซ่อนป้าย ระยะเริ่มตาม การเร่ง/ผ่อน การหยุดในเมนู การผ่านมุมเฟอร์นิเจอร์ และการช่วยงานด้วยความเร็วใหม่

### แก้การเดินค้างใกล้เฟอร์นิเจอร์จากผลตรวจระบบ

รอบตรวจเพิ่มเติมพบ Alice หยุดค้าง 13 จาก 114 คู่ตำแหน่งและช่วงเวลาเฟรม แม้หาเส้นทางได้ สาเหตุคือการตรวจแนวยาวด้วย CircleCast อาจพลาดมุมเฟอร์นิเจอร์ แต่การตรวจพื้นที่ปลายก้าวกลับพบว่าชน จึงหยุดแล้วหาเส้นทางเดิมซ้ำ แก้โดยตรวจพื้นที่ตลอดแนวเดินด้วย capsule footprint เดียวกันทั้งการวางเส้นทางและการเดินจริง ไม่ปิด collision ไม่เทเลพอร์ต และไม่เพิ่มความเร็ว

เพิ่ม `CompanionNavigationPlayTests` ถาวร 8 tests หลังแก้กรณีเดิมทั้ง 114 คู่เดินถึงทั้งหมด ไม่ทะลุสิ่งกีดขวางหรือเกินความเร็ว พร้อมล็อกจุดที่เคยค้าง ตรวจมุมตื้น ผนังบาง/หมุน/ทรงกลม สิ่งกีดขวางชั่วคราว การช่วยงาน/รางวัล เซฟ และอนิเมชันพักเมนู

## 6. สิ่งที่ยังไม่ยืนยันและควรทำต่อ

ตอนนี้เป็น **ต้นแบบที่ผ่านการทดสอบอัตโนมัติ local** ยังไม่มีผล API จริง ไม่ใช้โควตา และไม่อ้างว่า CI การเล่นภาพ/เสียงด้วยคน เครื่องเพื่อน หรือความสนุกผ่านแล้ว ตัวกรองภาษาและตัวแยกคำชวนยังไม่รับประกันทุกสำนวน ไม่มีชุดภาพเดินใหม่ และ NPC ยังทำกิจกรรมได้เฉพาะประเภทที่ระบบรองรับ

ลำดับถัดไปที่แนะนำ:

1. ลองเดโม Room01 ตั้งแต่เริ่มจนออกห้อง ทั้งแบบเล่นกับ Alice และไม่ชวนเลย ตรวจ UI การติดเฟอร์นิเจอร์ การหยุด/กลับมาช่วย และ save/load; เล่น Room02–03 เพื่อตรวจว่าไม่กระทบของเดิม
2. ให้คนที่ไม่รู้ระบบลองเล่น สังเกตว่าเข้าใจว่าพิมพ์ชวนเองได้ไหม รู้สึกว่า Alice ช่วยจริงหรือยัง และข้อความ/จังหวะไหนรบกวนการเล่น ผ่าน tests ไม่ได้แปลว่าสนุกแล้ว
3. เมื่อได้รับอนุญาตใช้โควตา ค่อยทดสอบ provider จริง แยกวัดการใช้ `{fact:}` / `{hint}` อัตรา fallback คำใบ้ตามความสัมพันธ์ และความเป็นธรรมชาติ ไม่ใช้ผล mock แทนผลนี้
4. หลังเลือกเวอร์ชันที่ทีมจะใช้ จึง commit/push branch และเปิด PR เทียบฐานที่ทีมต้องการ พร้อมแนบผลตรวจ/ตัวเกม ไม่ข้ามไป merge อัตโนมัติ
5. ถ้าต้นแบบสนุก ค่อยเพิ่มกิจกรรมที่มีการแบ่งหน้าที่หรือ NPC ชวนสำรวจแบบผู้เล่นเลือกตอบรับ มากกว่าการเพิ่มบทพูดสุ่มจำนวนมาก โดยยังไม่ให้ NPC ขัดการเล่นหรือเฉลยปริศนาเอง
