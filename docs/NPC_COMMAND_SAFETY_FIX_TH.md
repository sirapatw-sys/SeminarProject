# แก้บั๊กคำสั่ง NPC: การยกเลิกและเป้าหมาย

สาขา codex/npc-cothinking ต่อจาก f31a7e9 ตรวจเทียบ origin/develop แล้ว ไม่มี commit ที่ขาดอยู่ตอนเริ่มรอบนี้ การแก้ครั้งนี้ยังเป็นงาน local ไม่ได้ push หรือเปลี่ยน PR

## สิ่งที่แก้

1. คำยกเลิกท้ายข้อความหยุดงานที่กำลังทำจริง เช่น “ตามมา, ยกเลิก”, “ช่วยเปิดกล่องหน่อย, ยกเลิก” และ “ตามมา ยกเลิก” งานที่ยังไม่เสร็จไม่จบเองหลังปิดบทสนทนา และไม่ให้รางวัล/หลักฐานเพิ่ม
2. คำขอเดินตรวจทั้งการกระทำและเป้าหมายร่วมกันในเส้นทาง native parser และ AI proposal คำขอไปที่ประตู/เดินออกห่างไม่ถูกแปลงเป็นเดินตามผู้เล่นเพียงเพราะมีคำว่าเดิน ถ้า AI เสนอการกระทำที่ไม่ตรง จะใช้ข้อความถามกลับของเกม ไม่ใช้คำรับปากของ AI
3. คำขอช่วยใช้การตรวจสิ่งของที่เหลือหลังเอาชื่อสถานีออกชุดเดียวกัน ทั้ง native parser และ AI proposal จึงไม่ทิ้ง “ตู้หนังสือ” ใน “ช่วยจับขอบโต๊ะกับตู้หนังสือหน่อย” แล้วเริ่มช่วยโต๊ะเอง
4. ตรวจคำขอครบทั้ง clause ก่อนแยกคำเชื่อม เพื่อไม่ให้ “hold the desk and lift the chair” ทิ้งเป้าหมายที่สองไป

ไฟล์หลัก: Assets/Scripts/NPC/CompanionDialogueCommands.cs ไม่มีการเปลี่ยน GameState, puzzle dependencies, คะแนนรางวัล, range/modal guards หรือเพิ่มคำสั่งส่ง NPC ไปปลายทางอิสระ

## พฤติกรรมเดิมที่รักษาไว้

- “ยกเลิก, ตามมา” และคำขอใหม่หลังยกเลิกยังทำต่อได้ ไม่ถูกการยกเลิกก่อนหน้ากลืนทั้งข้อความ
- การอ้างคำพูด ข้อความสมมติ คำถามสถานะ และคำยืนยัน ไม่กลายเป็นคำสั่งยกเลิกหรือเคลื่อนไหว
- “ช่วยเปิดกล่องข้างประตู”, “ในห้องนี้”, “ได้หรือเปล่า”, “ช่วยจับอีกด้านของกล่อง” และคำชวนเดินเดิมยังใช้ได้
- คำขอคลุมเครือถามกลับโดยไม่รื้อหรือเปลี่ยนงานเดิมที่ NPC กำลังทำ
- Parse ยังคงเป็นการอ่านข้อมูลเท่านั้น ไม่สั่งงานหรือแก้ state
