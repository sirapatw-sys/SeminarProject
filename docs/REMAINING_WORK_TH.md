## ต้องทำก่อน: เปิด Unity ตรวจหนึ่งรอบ

ทำงานนอก Unity ทั้งหมด (Unity ในเครื่องรันแบบ batchmode ไม่ได้เพราะต้องล็อกอิน license) สิ่งที่ตรวจแล้ว:

- คอมไพล์ `MysteryGame.Runtime` และ `MysteryGame.Tests.EditMode` ผ่านด้วย Roslyn ของ Unity 2021.3.16f1 ไม่มี error/warning
- ทุก scene และ asset parse เป็น YAML ได้ ไม่มี fileID ซ้ำ ไม่มี reference ที่ขาด ทุก GUID หาไฟล์เจอ
- เงื่อนไขของ interaction ตรงกับ `steps[]` ทุกห้อง
- collider ทั้งสามห้องวางทับภาพแล้ว flood-fill ด้วยกล่องเท้าของผู้เล่นจากจุดเกิด: เดินถึงทุก trigger และไม่มีพื้นที่ว่างที่เดินไปไม่ถึง
- สคริปต์ใน `tools/art/` รันซ้ำแล้วได้ภาพเดิมทุกพิกเซล

ที่ยังต้องทำใน Unity:

1. เปิดโปรเจกต์ ให้ Unity import ภาพและเสียงใหม่
2. รัน `Window > General > Test Runner > EditMode` ทั้งหมด (**ยังไม่เคยรันจริง**)
3. เล่นตั้งแต่ Room01 จนจบ Room03 — ลองคลิกปุ่มใน popup ไอเท็ม/แป้นรหัส/หน้าตั้งค่า AI ด้วยเมาส์, ฟังความดังของเสียงสุ่มและเสียงประตู, ดูเรื่องชนกับเฟอร์นิเจอร์ (ระบบชนเปลี่ยนเป็นที่เท้าทั้งเกม), ขนาดตัว Rina/Stelle, ความดังของเสียงแต่ละชั้น ลองปรับขนาดหน้าต่าง Game หลายสัดส่วน (Free Aspect / 16:10 / 4:3) ภาพกับ hitbox ต้องตรงกันทุกแบบ
4. ถ้าเสียงชั้นไหนดัง/เบาเกิน ปรับที่ `sounds[].volume` ใน `Assets/Resources/Knowledge/Rooms/RoomXX.asset` ได้เลยไม่ต้องแก้โค้ด

| ตัวอ่านน้ำเสียงข้อความผู้เล่น | เขียนใหม่เป็น `PlayerToneClassifier` ทดสอบกับ 1,520 ประโยค 5 รอบ (รอบที่ยังไม่เคยเห็นได้ 63% / 58% / 72% / 62% ก่อนแก้ ส่วนที่พลาดเกือบทั้งหมดคือ "ไม่รู้จัก → กลางๆ") ตอนนี้ถูก 99.7% ของทั้งชุด ไม่มีประโยคดี/กลางๆ ถูกอ่านว่าหยาบ และไม่มีประโยคหยาบถูกอ่านว่าดี เปลี่ยนวิธีรวมกับ AI: ถ้ากฎกับ AI ขัดกันจะได้ 0 แทน -5 วัดทั้งระบบกับ AI จริง (`gpt-5.6-terra`, prompt แบบเดียวกับเกม) 396 ประโยค: AI อ่านประโยคหยาบถูก 131/132 ดี 131/132 แต่ให้คะแนนประโยคกลางๆ เกินไป (61/132 เป็น friendly/kind) และตัดสิน 3 ประโยคกลางๆ ว่า cold — ปรับ prompt ให้ "ติของ/ห้อง/ตัวเอง = neutral" และ "friendly/kind ต้องทำต่อตัวละครโดยตรง" ทดสอบซ้ำแก้ได้ 9/12 ประโยคหยาบที่ใช้คุมยังถูกทั้งหมด เหลือ "แล้วแต่" ที่ยังถูกอ่านว่า cold |
| แถบความสัมพันธ์ | ในกล่องบทสนทนา ท้ายแถวชื่อ มีรูปหัวใจ (`Assets/Resources/UI/pixel_heart.png` ย่อจาก `CopyPasteAssets/pixel heart.png` ให้คมแบบ pixel) ตามด้วย x/100 ของ NPC ที่กำลังพูดบรรทัดนั้น หัวใจเต้นทีหนึ่งเมื่อค่าเปลี่ยน ไม่แสดงตอนสำรวจสิ่งของ |
