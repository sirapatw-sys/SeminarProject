## สิ่งที่ต่อยอดให้รู้สึกว่า NPC อยู่ด้วยกัน

- ถ้า Alice เห็นการลองเปิดลิ้นชักล้มเหลว ผู้เล่นคุยว่า “ยังเปิดไม่ออกเลย” ได้ เธอจะให้กำลังใจและชวนทบทวนโดยไม่เฉลย
- ถ้าเธอเห็นเปิดสำเร็จจริง ปิดหน้าต่างไอเท็มแล้วพูด “เราทำได้แล้วค่ะ” ได้ เธอจะดีใจด้วยและยืนยันว่าผู้เล่นเป็นคนเลือกและทดลองเอง
- ถ้าเธอไม่ได้เห็น จะไม่สวมความทรงจำจากคำอ้างของผู้เล่นหรือเพียงเพราะ puzzle flag เป็นจริง
- บทสะท้อนเหตุการณ์ใช้ followUpPhrases/followUpLine ของ CompanionObservation เพิ่มเนื้อหาได้ผ่านข้อมูล ไม่เพิ่มสคริปต์เฉพาะ NPC
- บทตอบรับซ้ำไม่ให้คะแนนเพิ่ม และหลักฐานการเห็นเหตุการณ์อยู่ใน save flags เดิม
- ความทรงจำเหตุการณ์สำคัญอ้างกลับจาก observation/completion flags ได้ แม้ข้อความเก่าหลุดจากหน้าต่าง 128 รายการ

## ขอบเขตและงานที่ควรทำต่อ

1. ให้ผู้เล่นใหม่ลอง Room01 และเก็บว่ากลับไปปรึกษา Alice เองหรือไม่ เธอช่วยการตัดสินใจตรงไหน และจังหวะใดยังรู้สึกว่า NPC ไม่เข้าใจ
2. ปรับหัวข้อ/สำนวนจากข้อความที่คนใช้จริง การถามกลับยังสำคัญกว่าการเดาแล้วลงมือผิด
3. พิจารณา AI classification ของสมมติฐานแบบเลือกรหัสจากรายการปิดหลังมีตัวอย่างภาษาจริง โดยให้ engine เดิมเป็นผู้ตรวจความรู้และสิทธิ์ข้อมูล
4. การแยก framework ทั้งเกมยังต้องมี movement/UI/save adapters เพิ่ม สิ่งที่ย้ายข้ามโปรเจกต์และทดสอบแล้วรอบนี้คือโมดูลร่วมคิด
5. real-provider tests, Windows player build และการตรวจภาพ/เสียง/ความสนุกด้วยคนยังไม่ได้ทำ

ไม่เพิ่มห้องหรือระบบใหญ่ก่อนพิสูจน์ว่าการร่วมเล่นหนึ่งห้องนี้สร้างคุณค่าที่ผู้เล่นรับรู้ งานเก็บใน local branch; ยังไม่ push/เปิด PR/merge หรือส่ง comment ไปหาเพื่อน
