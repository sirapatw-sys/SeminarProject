## สิ่งที่ทำแล้ว

- Room01 เปลี่ยนจากอ่านรหัสตรง ๆ เป็นอ่านตัวเลขร่วมกับทิศลูกศร ผู้เล่นยังเป็นคนเลือกและทดสอบคำตอบ
- เส้นทางร่วมมือ: Alice เดินประคองโต๊ะจริง ผู้เล่นตรวจโต๊ะ แล้วเธอจึงรู้รอยลูกศร ส่วนตัวเลขต้องรับจากหลักฐานที่ผู้เล่นแบ่งปัน
- เส้นทางค้นหา: หลังพบโน้ต Alice เดินตรวจขอบกระดาษและเรียนรู้หลังตรวจเสร็จ ไม่ได้รู้จากข้อความ AI
- เส้นทางเดี่ยว: สำรวจโต๊ะซ้ำเพื่ออ่านรอยจางได้โดยไม่ต้องเพิ่มความสัมพันธ์
- พิมพ์ถามสิ่งที่เธอพบ แบ่งปันโน้ตด้วยชื่อสั้น ๆ และเสนอสมมติฐานที่ออกแบบไว้ได้
- คำตอบแยกหลักฐานไม่พอ/แนวคิดสอดคล้อง/แนวคิดขัดหลักฐาน และจำกัดรายละเอียดตามนโยบายความสัมพันธ์เดิม
- ความทรงจำทั่วไปจำกัด 128 รายการต่อ NPC และตัดส่วนเก่าบนการโหลดเซฟ; การระลึกกิจกรรมสำคัญอาศัย completion flag ได้แม้ข้อความเก่าถูกตัด
- รางวัลจากการช่วยและแบ่งปันยังผูกกับเหตุการณ์ที่ตรวจสอบแล้วและรับครั้งเดียว ไม่เพิ่มจากการเสนอสมมติฐานซ้ำ
- เพิ่ม local Unity package สำหรับโมดูลร่วมคิดพร้อม IReasoningWorld และตัวเชื่อม effect แบบลงทะเบียน ID
- มี sample ต่างธีม Mika ในห้องซ่อม พร้อม profile ที่แก้ใน Inspector ได้ และ script ตรวจการติดตั้งในโปรเจกต์ใหม่ที่เพื่อนรันซ้ำได้

ระหว่างพัฒนาพบ assertion เดิมผูกกับถ้อยคำโน้ตเก่า จึงเปลี่ยนให้ตรวจข้อความเทียบ canonical fact ปัจจุบัน ไม่ตัดการตรวจว่าผู้เล่นเห็นหลักฐานและไม่ได้เห็นเฉลยออก

ผลข้างเคียงจาก Unity tests เช่น runInBackground และ font atlas cache ถูกคืนเป็น baseline หลังจบ tests ไม่รวมในการเปลี่ยนแปลงเกม ผล XML/Logs เก็บใน ignored folders ใน worktree นี้ ส่วน template และ script สำหรับทดสอบติดตั้งเก็บใน repository แล้ว

## งานถัดไปที่มีคุณค่า

1. ให้คนที่ยังไม่เคยเล่นลอง Room01 โดยไม่บอกจุดขายก่อน แล้วดูว่ากลับไปปรึกษา Alice เองหรือไม่และอธิบายประโยชน์ของเธอได้ไหม
2. ปรับจังหวะ/ความชัดของหลักฐานจากผลเล่นจริงก่อนเพิ่มปริศนาหรือ NPC อีกตัว
3. ขยายสำนวนสมมติฐานจากคำที่คนใช้จริง โดยรักษาการถามกลับเมื่อไม่เข้าใจ และคงขอบเขตคำใบ้
4. ค่อยแยก movement/UI/save adapters ของ framework ทั้งเกมเมื่อมีเกมผู้ใช้รายที่สองที่ต้องการจริง
5. การทดสอบกับ real provider, Windows player build และ visual/audio/manual QA ยังเป็นงานที่ไม่ได้ยืนยันในรอบนี้

ยังไม่ push, เปิด PR, merge หรือส่ง comment ไปหาเพื่อน ใช้ branch local ที่มีคู่มือพร้อมส่งต่อ
