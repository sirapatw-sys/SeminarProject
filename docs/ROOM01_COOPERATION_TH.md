1. เปิด Room01 แล้วสำรวจภาพวาดตามเกมเดิม
2. ชวน Alice ด้วยการพิมพ์ `ตามเรามาหน่อย` แล้วปิดบทสนทนา
3. ไปแถวด้านล่างโต๊ะทำงาน เมื่อ Alice มี `?` ให้เข้าคุยแล้วพิมพ์ `มีอะไรอยากบอกไหม` เธอเสนอช่วยแต่ยังไม่เริ่มเอง
4. พิมพ์ `ช่วยจับขอบโต๊ะหน่อย` ปิดบทสนทนา เธอเดินไปจุดสีฟ้า ผู้เล่นไปจุดสีทองแล้วกด E ที่โต๊ะ
5. Alice จับขอบโต๊ะให้ ผู้เล่นเป็นคนสำรวจและอ่านโน้ต งานสำเร็จจึงเพิ่มความสัมพันธ์ +2 ครั้งเดียวและบันทึกความทรงจำ ไม่ได้ให้กุญแจหรือกรอกรหัสแทน
6. ลองพิมพ์ `หยุดช่วยก่อน` หรือ `ไม่ต้องแล้ว` ระหว่างงาน แล้วชวนใหม่ได้ การยกเลิกไม่หักความสัมพันธ์
7. พิมพ์ `เอาข้อความหลังกรอบภาพให้ดู` และ `เอากระดาษโน้ตจากขอบโต๊ะให้ดู` หลังพบหลักฐานจริง จากนั้น `ช่วยคิดด้วยกัน`
8. หลังร่วมสำรวจสำเร็จ พิมพ์ `จำขอบโต๊ะได้ไหม` เธออ้างประสบการณ์ที่เกิดจริง ถ้ายังไม่ได้ทำจะไม่แสร้งจำ

การแบ่งปันหลักฐานใช้ชื่อตรงตามหลักฐาน หรือภาษาอังกฤษ `share desk_note`/`share painting_arrow` เป็น adapter ขนาดเล็ก ไม่ได้อ้างว่าเข้าใจภาษาอิสระทุกรูปแบบ การพิมพ์อ้างว่าเจอของไม่เพิ่ม item หรือ knowledge ให้เอง

## เล่นคนเดียว

หลังสำรวจภาพวาด กด E ที่โต๊ะได้ตามเดิม เมื่อไม่มี Alice จับให้ จะมีความคืบหน้าการประคองและสำรวจประมาณ 5 วินาที อยู่ใกล้โต๊ะจนเสร็จ เดินออกหรือเปิดเมนูเพื่อยกเลิก ไม่มีโทษและไม่ต้องฟาร์มความสัมพันธ์ เมื่อสำรวจสำเร็จแล้วกลับมาอ่านซ้ำไม่ต้องรออีก การโหลดเซฟ/เริ่มใหม่ยกเลิกงานชั่วคราว

## สิ่งที่เปลี่ยน

- แก้คำปฏิเสธการกระทำในวรรคหลังให้ถอนคำขอเดิมที่ตรงกัน
- เดินตามหาจุดหยุดภายในพื้นที่ NPC ได้ แม้ผู้เล่นอยู่เลยขอบเขต NPC เล็กน้อย
- กิจกรรมสองชนิด: ยืนร่วมกันตามเวลาแบบกล่องเดิม และจับค้างจนผู้เล่นทำ interaction สำเร็จแบบโต๊ะ
- งานร่วมมี phase/revision และสถานะจบ/ยกเลิก/ล้มเหลว ไม่ใช้ข้อความ AI สร้างผลสำเร็จ
- ชวนคุยแบบผู้เล่นเลือกเองเมื่อกิจกรรมพร้อม ไม่มีปุ่มคำสั่งกิจกรรมใหม่
- การแบ่งปันหลักฐานผ่านข้อความใช้การตรวจสิทธิ์เดิมของ EvidenceSharing
- บททบทวนหลักฐานใช้กฎที่ทีมเขียนและเฉพาะ facts ที่ NPC รู้จริง กรณีเคยเห็นผู้เล่นล้มเหลวมีบททบทวนต่างออกไป ไม่มีการแต่งสมมติฐานเสรีหรือบอกรหัส
- เรียกความจำเก่าที่เกี่ยวกับกิจกรรม/เหตุการณ์จากคำถามก่อนความจำล่าสุด ไม่สร้าง memory ใหม่จากคำพูดผู้เล่น; ยังใช้ save เดิมได้
- คำตอบรับ/ข้อเสนอช่วยต่างตามความสัมพันธ์ แต่ไม่ปิดกั้นความสามารถช่วยงาน
- แสดงสถานะกำลังเดิน/จับค้างและท่าเอียงตัวเล็กน้อยจากการทำงานจริง แยก scene prop ออกจากกล่อง ไม่เพิ่มกล่องซ้อนโต๊ะ

## การตั้งข้อมูลเพื่อใช้กับห้องอื่น

`CompanionScenarioData.stations`: เว้น `holdForInteractionId` สำหรับกิจกรรมจับเวลาร่วมกัน; ใส่ interaction ID สำหรับจับค้างจนผู้เล่นสำเร็จ ตั้ง `useSceneProp` เมื่อใช้เฟอร์นิเจอร์ในฉาก กำหนดจุดสองฝ่ายไม่ชนกันและเงื่อนไขที่อนุญาตให้รู้จักกิจกรรมก่อนเผยคำแนะนำ

`InteractionData`: ใส่ `soloPreparationSeconds`, `helperNpcId`, `preparationLabel` และ `assistedMessage` เฉพาะ interaction ที่ต้องการทางเลือกช่วยกัน; ค่าเริ่มต้นไม่เปลี่ยนเกมอื่น

`observations.recallTerms`: คำค้นเรียกความจำ authored เดิมที่เกิดขึ้นจริง `discussions`: requiredFacts + conditions + line โดยรายการเฉพาะสถานการณ์มากกว่าต้องมาก่อน ห้ามใส่เฉลยลงบท authored เหล่านี้

## ขอบเขตที่ยังไม่ควรอ้างว่าทำครบ

- เป็น Room01 vertical slice ไม่ใช่ NPC ที่วางแผนเองได้ทุกอย่างหรือเข้าใจทุกประโยค
- ยังไม่ได้เพิ่มระบบสายตา/การได้ยินเต็มรูปแบบ ใช้เงื่อนไขระยะและเหตุการณ์ที่เกมยืนยันเดิม
- ความจำเลือกตามหัวข้อ authored และข้อความที่มีอยู่ ยังไม่ใช่ฐานเหตุการณ์แบบ structured/semantic retrieval เต็มรูปแบบ
- ยังไม่มี NPC หลายคนเจรจาแบ่งงานกันเอง เสียงพูด หรือปริศนาที่ AI สร้างเอง ตามลำดับที่เลื่อนไว้ในแผน
- ผล API จริง การตรวจภาพบนจอเดโม และผู้เล่นใหม่ 5–8 คนเป็นงานตรวจแยก ไม่ใช้ผล automated tests แทน
