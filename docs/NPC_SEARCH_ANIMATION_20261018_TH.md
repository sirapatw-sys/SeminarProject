# แก้จุดสำคัญและปรับท่าค้นหา — 18 ตุลาคม 2026

ต่อจากงานเพื่อน `2a34966` (`tanapoom/npc-cothinking-adjustment`) ที่นำมาต่อยอดแบบ fast-forward ในสาขาเรา `codex/npc-cothinking` ไม่แก้หรือ push สาขาของเพื่อน และไม่เพิ่มฟีเจอร์อื่น

## ขอบเขตสำคัญ

- คงข้อแก้ของเพื่อนเรื่องคำสั่งเดินออกห่างไม่กลายเป็นตาม, คำขอแบบคำบรรยายยังมี world context และการค้นหาใหม่ไม่ตอบผลตรวจเก่า
- อุดช่องว่างที่เหลือของ actionQuote: การคัดลอกข้อความคุยเล่นทั้งประโยคผ่านกฎ head/tail ได้ จึงเพิ่มเงื่อนไขรูปประโยคคำขอ ไม่ใช้การอ้างข้อความตรงตัวเป็นสิทธิ์ลงมืออย่างเดียว
- ก่อนแก้เพิ่ม regression สองกรณีบนฐานเพื่อนล่าสุด ทั้งสองล้มเหลวจริง: "วันนี้อากาศดีจัง" ถูกเสนอ follow พร้อม quote ทั้งประโยค และ "เหนื่อยจัง" ถูกเสนอ wait พร้อม quote ทั้งประโยค
- เพิ่มกรณีคำขอจริงที่ quote ทั้งประโยค เช่น "ช่วยปักหลักแป๊บนึง" เพื่อไม่ปิดความสามารถคำขอสุภาพที่ไม่อยู่ในคำกริยาเดิม
- ทั้งหมดเป็น provider จำลอง ไม่มีการยิง API หรือใช้โควตาจริง ไม่รับประกันว่าโมเดลทุกตัวจะตีความภาษาได้ถูกต้องทุกประโยค หากรูปคำขอไม่ชัดจะไม่ให้ quote ข้ามตัวตรวจเดิม

## ท่าค้นหา

- วงจร settle → มอง/ชะโงก → ก้มตรวจ → คืนท่า ใช้ WorkAnimationTime จากงานจริง วงจร 2.6 วินาที ไม่เพิ่มเวลาค้นหา/โอกาสพบหลักฐาน
- สัญลักษณ์แว่นขยายเล็กอยู่ใกล้ตัวละครและปรากฏเฉพาะ TaskPhase.Working ไม่มีข้อความหรือปุ่มเพิ่ม ระหว่างเดิน/หลังหยุดไม่แสดง
- ภาพตัวละครมีแขนในรูปอยู่แล้ว จึงไม่วาดแขนจำลองซ้อนในท่าค้นหา ท่าช่วยจับยังรักษาตำแหน่งมือและเงื่อนไขเดิม
- ใช้การเอียง/ก้มบน child artwork เท่านั้น ไม่ขยับ root, feet หรือ collider ไม่ย้ายตำแหน่งตรวจของจริง
- ลดการพลิกภาพซ้าย/ขวาจากค่าคลาดเล็กน้อยเมื่อวัตถุอยู่เกือบตรงหน้า และค่อยคืนท่าปกติหลังยกเลิก
- ไม่สร้างภาพตัวละครใหม่ ไม่เพิ่มโมเดล AI/ระบบปริศนา/คีย์ UI หรือเปลี่ยนความเร็วเดิน

## วิธีลอง
