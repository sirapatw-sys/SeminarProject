# หลักฐานและเหตุการณ์ต่อเนื่อง — 5 ตุลาคม 2026

ชุดนี้เพิ่มระบบแบ่งปันหลักฐาน และเรื่องต่อเนื่องหนึ่งเรื่องของ Alice ใน Room01 ไม่ได้เพิ่มค่าความไว้ใจแยกจากความสัมพันธ์ ปริศนาแบบหลาย NPC หรือตอนจบหลายแบบในรอบนี้

## วิธีลองเล่น

1. เปิด Assets/Scenes/Room01.unity แล้วเริ่มเกมใหม่ เหตุการณ์เปิดเรื่องจะพร้อมหลังเข้าห้องประมาณ 3 วินาที ถ้ายังไม่พบโน้ตหรือคุยเรื่องหลักฐานกับ Alice มาก่อน
2. เมื่อ Alice มี “!” ให้เดินเข้าไปกด E เธอชวนให้กลับมาคุยเมื่อพบหลักฐาน เลือกรับปากหรือปฏิเสธอย่างตรงไปตรงมาได้ ไม่บังคับหยุดเล่น
3. สำรวจภาพวาด หรือค้นโน้ตจากขอบโต๊ะตามข้อความที่พบ
4. เปิดหน้าคุยกับ Alice แล้วกด “หลักฐาน” รายการจะมีเฉพาะสิ่งที่พบจริงในห้องนั้น เลือกข้อความหลังกรอบภาพ โน้ต หรือกุญแจที่พบแล้วได้
5. Alice อ่านข้อมูลจริงและตอบด้วยคำอธิบายที่ผู้เขียนเกมกำหนด หากความสัมพันธ์ต่างกัน ปฏิกิริยาบางหลักฐานจะต่างกันด้วย จากนั้นพิมพ์ถาม AI ต่อหรือขอคำใบ้ได้ตามปกติ
6. ถ้ารับปากและนำหลักฐานชิ้นใดมาให้ดู ให้ปิดหน้าคุย รอสัญญาณ “!” ถัดไป แล้วคุยเรื่องรักษาสัญญา ผลที่เลือกจะเปลี่ยนความสัมพันธ์ ความทรงจำ และบททักทายในครั้งถัดไป
7. หากรับปากแต่เปิดลิ้นชักได้โดยยังไม่กลับมาให้ดูหลักฐาน จะมีเหตุการณ์อีกผลลัพธ์หนึ่ง เลือกขอโทษหรือปัดความรับผิดชอบได้ หากไม่ได้รับปาก จะไม่ถูกลงโทษว่าเสียสัญญา
8. กด F5 เพื่อเก็บผลระหว่างอยู่ในห้อง หรือใช้การบันทึกอัตโนมัติเมื่อเข้าห้องถัดไป แล้วลองโหลดกลับ ผลการแบ่งปันหลักฐานและการตัดสินใจติดไปกับเซฟ

ปุ่มปิดและ Escape ใช้ได้เสมอ: Escape ขณะเปิดรายการหลักฐานจะปิดรายการก่อน กดอีกครั้งจึงปิดหน้าคุย เหตุการณ์ที่ต้องเลือกจะไม่นับว่าทำแล้วถ้าปิดก่อนเลือก และจะกลับมาชวนหลังช่วงพัก ไม่สามารถพิมพ์หรือแบ่งปันหลักฐานแทนการยืนยันตัวเลือกของเหตุการณ์นั้นได้

หากยังไม่พบหลักฐาน รายการจะบอกให้สำรวจ ไม่แสดงชื่อของสิ่งที่ยังไม่พบ ระหว่างรอคำตอบ AI ปุ่มหลักฐานจะใช้ไม่ได้เพื่อไม่ให้สถานะเปลี่ยนกลางคำขอ

## ขอบเขตข้อมูลและ AI

- การค้นพบเป็นข้อมูลของผู้เล่น การแบ่งปันเป็นความรู้แยกตาม NPC การสำรวจของผู้เล่นไม่ทำให้ Alice รู้ข้อเท็จจริงของหลักฐานทั้งสามชิ้นทันทีอีกต่อไป
- ต้องกดเลือกหลักฐานจริง ข้อความที่พิมพ์ว่า “ฉันให้โน้ตแล้ว” หรือข้อความที่ AI แต่งไม่ทำให้เกิดการแบ่งปันหลักฐาน
- ระบบตรวจห้องปัจจุบัน การค้นพบ ข้อห้ามของ NPC และสถานะปริศนาซ้ำขณะเลือก ไม่รับ fact ID ปลอม และไม่เปิดให้แบ่งปัน fact ที่เป็นคำเฉลยปริศนา
- การแบ่งปันไม่ใช้ไอเท็มหมด ไม่ไขลิ้นชักหรือประตูให้เอง และให้คะแนน/ความทรงจำ/บันทึกหลักฐานเพียงครั้งเดียวต่อ NPC/ห้อง/fact
- ปฏิกิริยาต่อหลักฐานและตัวเลือกที่เป็นสัญญาใช้ข้อความที่เขียนไว้ เพื่อให้ข้อความตรงกับผลของตัวเลือก ส่วนบทคุยอิสระหลังจากนั้นยังใช้ AI เดิมและส่งความรู้ที่เพิ่งได้รับเข้าไปได้
- คำใบ้ยังเลือกจากขั้นด่านและความสัมพันธ์ตามเดิม ไม่ต้องทำเหตุการณ์นี้หรือแบ่งปันหลักฐานจึงจะผ่านห้องได้
- ผลของเหตุการณ์เป็น flags และ actions ที่เขียนไว้ AI ไม่มีสิทธิ์สร้างเงื่อนไขผ่านด่านหรือแก้ผลสัญญาเอง บทคุยอิสระยังมีข้อจำกัดของการกรองทางความหมายตามคู่มือ framework
- ยังไม่ได้บันทึกตำแหน่งตัวละครหรือ cooldown/pending event ข้ามการปิดเกม แต่ความรู้และผลที่เลือกแล้วบันทึกใน StateSnapshot เดิมได้ ไม่มีการเปลี่ยนรูปแบบเซฟ

## ให้ทีมต่อยอดผ่าน Inspector

### หลักฐานชิ้นใหม่

1. เพิ่ม RoomFact ใน RoomKnowledgeData ของห้อง ตั้ง factId ไม่ซ้ำและ statement ให้เป็นข้อมูลจริง
2. เปิด canShareAsEvidence ตั้ง evidenceTitle ให้อ่านรู้เรื่อง และกำหนด revealedWhen ให้ตรงกับการสำรวจ/ไอเท็มจริง ไม่ใส่คำเฉลยลงใน statement ของหลักฐานทั่วไป
3. ถ้า NPC ควรรู้หลังผู้เล่นนำให้ดูเท่านั้น อย่าใส่ fact นั้นใน knownFactIds หรือให้ learnedFacts เปิดจาก flag การสำรวจ ระบบจะให้ความรู้จากการแบ่งปันเอง
4. ใส่ evidenceReactions ใน NpcProfileData หากต้องการคำอธิบายเฉพาะ: factId, when, reply, repeatReply และ relationshipDelta (-15 ถึง +10 คะแนนจริง ไม่คูณสเกลตัวเลือก)
5. เรียงปฏิกิริยาที่เฉพาะเจาะจงไว้ก่อน เช่น ความสัมพันธ์ต่ำ/สูง แล้วค่อยปฏิกิริยาทั่วไป ระบบเลือกข้อแรกที่ตรง ถ้าไม่เขียนปฏิกิริยา จะใช้การรับทราบข้อมูลแบบกลางๆ โดยไม่ให้คะแนน

สิ่งที่เป็นความลับหรือคำเฉลยยังใช้ระบบเดิม ห้ามเปิด canShareAsEvidence เพื่ออ้อมข้อห้ามเหล่านั้น เครื่องมือตรวจเนื้อหาจะรายงานการตั้งค่าที่ผิด

### เหตุการณ์หลายช่วง

ใช้ MiniEventData + DialogueData + ConditionRule/ActionCommand เดิม ไม่ต้องเพิ่มสคริปต์ชื่อ NPC หรือสร้างระบบเควสต์ซ้ำ:

- ตั้ง storyBeat = true ให้ตรวจตามสถานะ ไม่รอการสุ่ม และ autoStart = false ให้ผู้เล่นกดคุยเอง
- ใช้ conditions อ้าง flag ที่ได้จากตัวเลือก/หลักฐานครั้งก่อน และ MissingFlag ของผลสรุป เพื่อไม่ให้สองผลลัพธ์เล่นพร้อมกัน
- เปิด completeOnChoice และปิด repeatable เพื่อบันทึก CompletedFlag หลังเลือกจริง ปิดหน้าคุยก่อนเลือกไม่ถือว่าจบเหตุการณ์ และการคลิกตัวเลือกซ้ำไม่ทำผลซ้ำ
- เหตุการณ์สัญญาในตัวอย่างปิด useAiDialogue/freeTopic เพื่อคงความหมายตัวเลือกให้ตรงกับ actions ถ้าเปิด AI สำหรับเรื่องอื่น ต้องตรวจความสอดคล้องของบทและผลด้วย
- ผูก MiniEventData เข้ารายการ events ของ NpcEventController ใน scene และรัน Mystery Game > Validate Content กับ Test Runner ก่อนส่งงาน

flags ที่ระบบหลักฐานสร้าง (ใช้ IDs จริงของ NPC และห้อง):

```text
evidence.Alice.Room01.painting_arrow.shared
evidence.Alice.Room01.desk_note.shared
evidence.Alice.Room01.drawer_key.shared
evidence.Alice.Room01.shared_any
```

เรียก EvidenceSharing.SharedFlag(npcId, roomId, factId) หรือ AnySharedFlag(npcId, roomId) เมื่อต้องอ้างจากโค้ด ชื่อที่มีจุดหรืออักขระพิเศษจะถูก encode เพื่อไม่ให้ flags ชนกัน

เนื้อหาตัวอย่างอยู่ใน Assets/Data/Events/Alice_EvidencePromise_Event.asset, Alice_PromiseKept_Event.asset และ Alice_PromiseMissed_Event.asset ส่วนความรู้และปฏิกิริยาอยู่ใน Assets/Resources/Knowledge/Npcs/Alice.asset กับ Rooms/Room01.asset

## การตรวจสอบ

### สิ่งที่แก้หลังตรวจซ้ำ

- เหตุการณ์เนื้อเรื่องไม่ต้องรอ AI ของเหตุการณ์สุ่มจนค้าง ถ้าผู้ให้บริการจบโดยไม่เรียก callback, เกิด exception หรือเกิน generationTimeoutSeconds จะใช้บทสำรอง คำตอบช้า/ซ้ำถูกทิ้ง และการปิด NPC ยกเลิกคำขอพร้อมปล่อยทรัพยากร
- บททักทายเลือกตามสถานะที่เปลี่ยนและความสัมพันธ์ก่อนผลสัญญา ผลสัญญายังเก็บในเซฟ แต่ไม่บังคับให้พูดประโยคเดิมในทุกห้อง ConditionType.CurrentScene ใช้จำกัดกฎตามห้องได้
- ปฏิกิริยา desk_note หลังเปิดลิ้นชัก/ผ่านห้องไม่แนะนำให้ไขลิ้นชักซ้ำ รางวัลและความรู้ยังใช้หลักฐานที่แบ่งปันจริงเพียงครั้งเดียว
- PersonalFact เพิ่ม protectedTerms สำหรับวลีเฉพาะและชื่อเรียกอื่นของรายละเอียดส่วนตัวที่ห้ามหลุดนอก fact เช่น “น้องชาย”, “younger brother” ตั้งให้ครอบคลุมความลับที่ล็อกตามเงื่อนไข หลีกเลี่ยงคำกว้างอย่าง “คิดถึงบ้าน” เพื่อไม่ปิดบทคุยเรื่องอารมณ์ เครื่องมือตรวจเนื้อหาจะแจ้ง fact ที่มีเงื่อนไขแต่ไม่มีคำป้องกัน
- การตรวจวลีช่วยกันข้อความที่รู้จักและการแยกคำด้วยเครื่องหมาย/ตัวอักษรล่องหน/บรรทัดใหม่ แต่ไม่รับประกันทุกความหมายหรือทุกภาษา เรื่องส่วนตัวที่เปิดแล้วให้ AI ใช้ `{fact:factId}` พร้อม referencedFactIds ไม่เรียบเรียงรายละเอียดเอง
- protectedTerms ของข้อมูลห้องตรวจข้อความรวมด้วย ไม่ตรวจเฉพาะบรรทัดเดี่ยว รวมคำตอบที่สะกดตัวเลขข้ามบรรทัดและบท/ตัวเลือกของ mini event
- ค่าหิวและอารมณ์ที่เพิ่มเองไม่ไปกระตุ้นบททักทายว่าผู้เล่นทำด่านคืบหน้า แต่ยังเรียกเหตุการณ์ตาม threshold ได้ ค่าที่บันทึกในเซฟไม่เปลี่ยนรูปแบบ

เพิ่มเงื่อนไข RoomProgressSinceLastTalk สำหรับบทที่อ้างถึงความคืบหน้าห้อง แยกจาก world revision ทั่วไป จึงไม่อ้างว่าผู้เล่นทำปริศนาเพิ่มเพียงเพราะคะแนนสัมพันธ์/ความทรงจำ/dialogue flags เปลี่ยน หลักฐานที่ค้นพบและ inventory ที่เปลี่ยนยังทำให้บทตอบสนองได้ตามจริง

NPC events ไม่เริ่มคำขอ AI ใหม่ระหว่างเมนู/intro/transition ทั้งเส้นทาง random, story beat preemption และ QueueEvent แต่คำขอที่เริ่มแล้วก่อนช่วงดังกล่าวยัง timeout/dispose ได้ event ที่รออยู่ยังหมดอายุและปฏิเสธ callback เก่าได้ เมื่อกลับมาเล่นยังเข้าคิวเป็น soft invitation ตามเดิม

GameState.StateReset แยกการเริ่มเกมใหม่จาก restore เซฟ ค่าเริ่มต้น needs/emotions กลับมาตาม scene ทันทีหลัง reset ส่วนค่าที่มีอยู่ในเซฟไม่ถูกทับ ตัว UI ที่ซ้ำตอนโหลดฉากไม่เปลี่ยนสถานะ AI modal ของเจ้าของ และ transition ปิดหน้าตั้งค่าก่อนโหลดห้อง

หน้าคุยใช้ AiRequestOperation ยกเลิกและ dispose iterator ซ้อนเมื่อปิด หมดเวลา disable หรือเปลี่ยนห้องแล้ว ส่วนหน้าตั้งค่า AI ทิ้งผลเก่าที่ไม่ตรงเลขรอบและ provider/endpoint/key/model ปัจจุบัน ปุ่มทดสอบใช้ค่าบนฟอร์มทันที ไม่ใช้ค่าที่บันทึกครั้งก่อน
