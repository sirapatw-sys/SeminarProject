# แก้เฉพาะขอบเขตคำสั่งค้นหา

สาขา codex/npc-cothinking ต่อจาก 0b8d527 ตรวจเทียบ origin/develop ตอนเริ่มงานแล้ว ไม่มี commit ที่ขาดอยู่ ยังไม่ push/เปลี่ยน PR

## ขอบเขตตามที่ผู้ใช้เลือก

แก้เฉพาะคำสั่งค้นหาและการถามกลับ ไม่เปลี่ยนการแยกข้อความ/การยกเลิก และไม่แก้ประเด็นคำใบ้จากข้อความหลายช่วงที่ผู้ใช้ให้พักไว้ จึงไม่ถือว่าปัญหานั้นได้รับการแก้ในรอบนี้

## พฤติกรรมหลังแก้

- “ช่วยหาหลักฐานหน่อย” และ “ช่วยค้นห้องหน่อย” ยังเริ่มเส้นทางค้นหารอบห้องที่ออกแบบไว้
- “ช่วยหาหลักฐานในลิ้นชักเท่านั้น” จะไม่ถูกแปลงเป็นค้นทั้งห้อง NPC อธิบายข้อจำกัดก่อน ไม่เดินหรือได้หลักฐานจากจุดอื่นเอง
- “ช่วยหาหลักฐานแล้วช่วยยกเก้าอี้หน่อย” ไม่ทิ้งงานที่สองแล้วเริ่มค้นหาบางส่วนเอง
- ใช้ตัวตรวจขอบเขตเดียวกันใน native parser และ AI proposal ไม่ลบชื่อลิ้นชักทิ้งเหมือนเป็นคำบอกตำแหน่งทั่วไป และไม่ลบชื่อสถานีออกเพื่อให้ search ผ่าน
- ถ้า AI เสนอ search สำหรับ “inspect the desk please” จะไม่เปลี่ยนไปช่วยจับโต๊ะเอง แต่ถ้าผู้เล่นขอช่วยโต๊ะจริง ๆ เช่น “ไปช่วยตรงโต๊ะหน่อยสิ” ยังแก้ proposal ให้ตรงกับกิจกรรมโต๊ะตามเดิม
- ผู้เล่นยืนยันค้นรอบห้องด้วยการพิมพ์คำขอใหม่ ไม่มีปุ่มเลือกเพิ่ม และไม่จำเป็นต้องใช้จุลภาคแบ่งหลายคำขอ
- คำขอค้นที่ถูกปฏิเสธไม่รื้อกิจกรรมเดิมที่ได้รับอนุญาตไว้ หากต้องการหยุดกิจกรรมนั้นให้พูด “หยุดเดิน” หรือ “ยกเลิก” ตามเดิม

ยังไม่ได้เพิ่มระบบเดินค้นเฉพาะสิ่งของจริง ขอบเขตที่รองรับคือ room search เท่านั้น นี่คือการป้องกันลงมือผิด ไม่ใช่การอ้างว่ารองรับเป้าหมายอิสระแล้ว

## ตั้งค่าบทพูด

CompanionScenarioData.searchScopeLine เป็นข้อความอธิบายข้อจำกัด ปรับใน Inspector ได้ และรวมอยู่ใน SpokenLines/ValidateConfiguration เพื่อป้องกันหลุดคำสั่งควบคุมเกมในบทพูด

ไฟล์ runtime ที่เปลี่ยน: Assets/Scripts/NPC/CompanionDialogueCommands.cs และ CompanionScenarioData.cs ไม่มีการเปลี่ยน DialogueManager, hint policy, puzzle conditions หรือโมดูล reasoning
