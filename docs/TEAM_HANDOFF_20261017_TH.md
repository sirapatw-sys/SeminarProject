## เส้นทางลองเล่นในห้องแรก

1. เปิด `Assets/Scenes/Room01.unity` กด Play เลือก New Game และจบบทนำ
2. กด C แล้วพิมพ์ `โซฟาอยู่ตรงไหน` ต้องตอบตำแหน่งโดยไม่เดิน
3. พิมพ์ `ไปยืนตรงที่ว่างระหว่างโต๊ะกับประตูหน่อย` ต้องเดินจริงไปยังพื้นที่ว่าง ไม่ยืนทับของ/teleport
4. พิมพ์ `ช่วยไปดูโต๊ะข้างโซฟาหน่อย` ต้องตรวจโต๊ะเล็ก ไม่ใช่โต๊ะทำงาน และไม่เกิดหลักฐานปริศนาใหม่เอง
5. พิมพ์ `ช่วยไปตรวจภาพวาดหน่อย` หรือ `ลองเช็คโต๊ะให้หน่อย` Alice เดินไปดูภายนอก แต่ต้องไม่ตั้ง inspected_painting/found_note หรือรู้ข้อความลับเอง ปิด C แล้วไปกด E สำรวจภาพวาดและโต๊ะด้วยผู้เล่น หรือชวนช่วยประคองก่อนที่ผู้เล่นตรวจโต๊ะ
6. พิมพ์ `ช่วยอ่านโน้ตให้หน่อย` ต้องอ่านหลักฐานที่พบจริง ไม่สรุปรหัสให้แทน
7. ถ้าจะลองเส้นทางช่วยจับโต๊ะ ให้เริ่ม New Game อีกรอบและทำตาม [คู่มือร่วมคิด](NPC_COTHINKING_QUICKSTART_TH.md) ก่อนพบโน้ต เพราะกิจกรรมนี้ไม่เปิดให้ทำซ้ำหลังพบแล้ว จากนั้นถามสิ่งที่พบหรือเสนอสมมติฐานที่คู่มือรองรับ ผู้เล่นยังมีทางตรวจขอบกระดาษเอง
8. ระหว่างเดินลอง `หยุดก่อน` หรือส่งคำขอใหม่ ต้องไม่กลับไปทำงานเก่าจาก callback ที่มาช้า กด Esc ปิด C แล้วเปิดกลับเพื่อดูผลได้

ต้องทดสอบถ้อยคำใหม่กับ AI ที่ตั้งใน F10 ด้วย เช่น `ภาพวาดนั่น ฝากพิจารณารายละเอียดให้ที` เส้นทางนี้อาศัยโมเดล ไม่ใช่ parser local ทั้งหมด การทดสอบ connection/คุยจริงใช้โควตาของบัญชีผู้ทดสอบ ใส่คีย์เอง ห้าม commit คีย์

พิมพ์คุยในภาพเต็ม E ใช้ semantic proposal ได้เช่นกัน แต่ต้องปิดบทคุยก่อน NPC เดิน นี่เป็น pause policy เดิม ไม่ใช่ NPC ไม่รับงาน

## หลักฐานที่ยืนยันแล้ว และสิ่งที่ยังไม่ยืนยัน

ทดสอบ local ด้วย Unity 2021.3.16f1 ที่โค้ด `e58d66c` ตรวจไฟล์ผลจริงอีกครั้งตอนจัดส่งต่อ ไม่ได้รันใหม่เพียงเพราะแก้เอกสาร

| ขอบเขต | ผล |
| --- | --- |
| EditMode | 1,296/1,296 ผ่าน ล้มเหลว 0 ข้าม 0 |
| PlayMode | 348/348 ผ่าน ล้มเหลว 0 ข้าม 0 |
| รวมสองชุด | 1,644 กรณี ไม่รวมการนับรันซ้ำ/ชุดย่อย |
| Windows AI-enabled release build | สำเร็จ errors=0 ไม่เปิด NPC_PLAYTEST_BUILD |
| KKU / provider จริง | ยังไม่ทดสอบในรอบนี้ ใช้ provider จำลอง/ออฟไลน์ |
| การเล่นตรวจภาพด้วยคน / ความสนุก / FPS | ยังไม่ยืนยัน ไม่อนุมานจาก tests |

ค่าอ้างอิง SHA256 และผลสรุปอยู่ใน [verification digest](verification/NPC_SEMANTIC_WORLD_20261017.json) ส่วน XML/log ต้นฉบับและ ZIP อยู่ใน Logs ของเครื่องผู้พัฒนาและถูก ignore จึง **ไม่ได้มาพร้อม clone** ไม่ใช่ผล CI หรือหลักฐานอิสระจากเครื่องเพื่อน

ให้เพื่อนรันซ้ำผ่าน Window > General > Test Runner ทั้ง EditMode และ PlayMode หรือใช้คำสั่งด้านล่างจากราก repository (ปิด Editor ของโปรเจกต์นี้ก่อน และสร้างโฟลเดอร์ Logs ไว้):

```powershell
$npcUnity = 'C:/Program Files/Unity/Hub/Editor/2021.3.16f1/Editor/Unity.exe'
$npcProject = (Get-Location).Path
New-Item -ItemType Directory -Path "$npcProject/Logs" -Force | Out-Null
foreach ($npcPlatform in @('EditMode', 'PlayMode')) {
    $npcArgs = '-batchmode -nographics -job-worker-count 2 -projectPath "' + $npcProject + '" -runTests -testPlatform ' + $npcPlatform + ' -testResults "' + $npcProject + '/Logs/Team' + $npcPlatform + '.xml" -logFile "' + $npcProject + '/Logs/Team' + $npcPlatform + '.log"'
    $npcProcess = Start-Process -FilePath $npcUnity -ArgumentList $npcArgs -WindowStyle Hidden -Wait -PassThru
    if ($npcProcess.ExitCode -ne 0) { throw "Unity $npcPlatform failed: $($npcProcess.ExitCode)" }
}
```

ไม่ใส่ `-quit` ในคำสั่ง Test Runner สคริปต์รอชุดแรกจบก่อนเปิดชุดถัดไป ต้องตรวจผล XML ด้วย ไม่ถือว่าเปิดโปรแกรมสำเร็จเท่ากับ tests ผ่าน

สร้างเกมเองได้จากเมนู **Mystery Game > Playtest > Build AI-Enabled Windows Demo** ส่วน **Build Offline Windows Demo** ตั้งใจปิด AI อย่าใช้ฉบับนั้นตรวจ provider จริง ZIP ล่าสุดชื่อ `MysteryGame-AI-Enabled-SemanticWorld-20261017.zip` เป็น artifact local ที่ส่งให้เจ้าของงานแล้ว ไม่ได้อัปโหลดเข้า Git

## งานถัดไปที่ควรโฟกัส

1. รัน tests และลองฉากจริงบนเครื่องเพื่อนก่อนแก้ต่อ โดยเฉพาะ C/E, หยุดงาน, คำถามไม่ใช่คำสั่ง, Inspect ไม่กลายเป็น Open และการตรวจของตกแต่ง
2. ใช้คีย์ของผู้ทดสอบเองทดสอบ KKU จริงกับประโยคที่ไม่ได้ลอกคำสั่งจากคู่มือ บันทึกข้อความ/เจตนา/เป้าหมาย/ทิศ/สิ่งที่เกมทำจริง/เวลารอ และตัดข้อมูลส่วนตัวออก ไม่บันทึกคีย์ ไม่ใช้ผลจำลองแทนอัตราเข้าใจภาษา
3. ให้คนที่ไม่เคยเล่นลองห้องแรก ดูว่ากลับไปหา Alice เองไหมและบอกประโยชน์ของเธอได้หรือไม่ ใช้ [แบบบันทึกผล](PLAYTEST_RESULTS_TH.md) ปัจจุบันยังไม่มีผลผู้เล่นจริง
4. เลือกแก้ปัญหาที่ทำให้ผู้เล่นร่วมมือไม่สำเร็จจากข้อ 2–3 ก่อนเพิ่มห้องหรือเพิ่มระบบใหม่

ยังไม่รองรับการสั่งทำอะไรก็ได้ การชี้เมาส์/พิกัดอิสระ การลากของ การนั่งบนโซฟา หรือหลายงานพร้อมกัน ทิศหน้า/หลังอิงจอ ไม่ใช่ทิศตัวละครหัน เมื่อเป้าหมายย้ายจะยกเลิกและขอคำสั่งใหม่ ไม่ไล่ตามวัตถุที่เคลื่อนตลอดเวลา ยังไม่ได้ติดตั้งหรือฝังโมเดล local
