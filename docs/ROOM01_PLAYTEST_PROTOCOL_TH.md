# ทดลอง Room01 กับผู้เล่นใหม่
สถานะ: แบบดำเนินการพร้อมใช้ ยังไม่มีผลจากผู้เล่นจริง
ใช้คู่กับ SOL_NPC_VALUE_PLAN_TH.md และบันทึกผลลง PLAYTEST_RESULTS_TH.md

## เตรียมก่อนเริ่ม
- ใช้ Offline Windows Demo ที่สร้างจาก Mystery Game > Playtest > Build Offline Windows Demo หรือเริ่ม trace ใน Unity Play Mode ผ่าน Mystery Game > Playtest > Start Local Trace
- เดโม build นี้ปิด AI/network สำหรับบทคุย การถอดเสียง และการขอรายชื่อโมเดล ใช้การพิมพ์คุย
- แจ้งผู้เล่นก่อนว่าเก็บชนิดเหตุการณ์และเวลาในเครื่องเพื่อปรับเกม ไม่เก็บข้อความที่พิมพ์ลง trace หากจะจดคำพูดตัวอย่างหรืออัดคลิปให้ขอความยินยอมแยก
- ใช้ New Game สำหรับผู้เล่นแต่ละคน หลีกเลี่ยงการใช้เซฟของผู้เล่นก่อนหน้า; trace หนึ่งไฟล์ต่อผู้เล่น โดยปิดเกมแล้วเปิดใหม่เมื่อเปลี่ยนคน
- ระบุรหัสผู้เล่น เช่น P01, build ID, วันที่, รูปแบบการเล่น, ผู้ดูแล และเลข session จาก trace โดยไม่เก็บชื่อจริง
- ผลออฟไลน์ใช้วัด flow/การร่วมมือและความชัดของ NPC ไม่ใช้แทนคุณภาพภาษาโมเดลจริง

## คำชี้แจงให้ผู้เล่น
“ลองหาทางออกจากห้องนี้ได้เลย เดินด้วยปุ่มที่เกมบอก และกด E เพื่อสำรวจหรือคุย เวลาคุยสามารถพิมพ์ข้อความเองได้ ถ้าติดบอกเราได้”

อย่าบอกก่อนว่าต้องไปขอ Alice ช่วยอะไร อย่าแจกประโยคตัวอย่างจากคู่มือพัฒนา ช่วงแรกให้ผู้เล่นตัดสินใจเอง
จบรอบเมื่อผู้เล่นออกจาก Room01 ได้ หากเกมพาไป Room02 ให้หยุดเก็บเส้นทางเดโมห้องแรกแล้วเริ่มคำถามหลังเล่น

## สิ่งที่ผู้ดูแลจด
| เวลา | เหตุการณ์ที่เห็น | ผู้เล่นทำเอง/มีคนบอก | อาการติดหรือคำพูดที่อนุญาตให้จด |
| --- | --- | --- | --- |
| รอเก็บจริง | | | |

สังเกตว่าพบสัญญาณชวนคุยไหม กลับไปปรึกษาเองไหม รู้ว่าใครมีข้อมูลอะไร เห็นการลงมือช่วยไหม เสนอสมมติฐานหรือทดลองเองไหม และการถามกลับช่วยให้ไปต่อได้หรือไม่

ถ้าติดนานให้บันทึกระยะเวลาก่อนแทรกแซง บอกเป็นระดับ: เตือนการควบคุม → เตือนว่าสนทนาได้ → บอกทิศทาง → บอกข้อความตรง ๆ ทุกครั้งที่ช่วยต้องจด ไม่ถือว่าขั้นนั้นผู้เล่นค้นพบเอง
เป้าหมายเดโม 5–8 นาทีใช้เป็นแนวทาง หากยังเล่นต่อให้เก็บเวลาจริง ไม่ตัด/เติมผลให้เข้ากับเป้าหมาย

## หลังเล่น
ถามโดยไม่ชี้นำ:
1. Alice ช่วยอะไรในการเล่นครั้งนี้บ้าง?
2. ตอนไหนรู้สึกว่ากำลังทำด้วยกัน?
3. ตอนไหนรู้สึกว่าเธอไม่เข้าใจหรือพูดไม่เกี่ยว?
4. ใครเป็นคนคิดและเลือกคำตอบของปริศนา?
5. ถ้าจะเล่นต่อ อยากกลับไปคุยกับเธอเรื่องอะไร?

ให้คะแนน 1–5 พร้อมเหตุผล: มีประโยชน์ / รู้สึกมีเพื่อน / ตนยังได้ตัดสินใจ การตอบคะแนนสูงอย่างเดียวไม่แทนตัวอย่างพฤติกรรมที่เกิดขึ้นจริง

## เก็บหลักฐาน
- ปิดเกมก่อนเก็บไฟล์ trace จาก persistentDataPath/Playtests; ใน Editor ดู path ที่แจ้งตอน Start Local Trace
- Windows ค่า persistentDataPath ปกติอยู่ใต้ AppData/LocalLow ตาม company/product ของโปรเจกต์ ตรวจจาก Application.persistentDataPath เมื่อไม่แน่ใจ
- ใช้ tools/Summarize-CompanionPlaytest.ps1 -TracePath <ไฟล์.jsonl> เพื่ออ่านจำนวนเหตุการณ์และเวลารอ
- trace ไม่บอกว่าผู้เล่นรู้สึกสนุกหรือเข้าใจ ต้องใช้ observation และคำตอบหลังเล่นประกอบ
- trace เวลา invitation ในรอบนี้หมายถึงฟองรายงานหลักฐานที่ HUD สั่งวาด ไม่ใช่หลักฐานว่าผู้เล่นมองเห็นหรือเข้าใจแล้ว เครื่องหมาย event เดิมให้ผู้ดูแลจดประกอบ
- อย่าเผยแพร่ไฟล์ Player.log หรือ save ทั้งก้อนโดยไม่ตรวจเนื้อหา เพราะระบบเดิมอาจบันทึกข้อความเกม/บทคุยไว้ แม้ trace ใหม่ไม่มีข้อความเหล่านั้น
- เริ่มจาก 3–5 คน รายงานจำนวนจริง ใช้หาปัญหาการเล่นรอบต้น ไม่อ้างนัยสำคัญทางสถิติหรือเหนือกว่าเกมอื่น
