# Room01: เพื่อนร่วมสำรวจ — ต้นแบบ

เป้าหมาย: ให้ Alice มีส่วนร่วมในการเล่นจริง ไม่ใช่เพียงยืนตอบคำถามหรือแจกคำใบ้ เพิ่มเฉพาะห้องแรกโดยไม่บังคับให้เล่นกิจกรรมใหม่เพื่อผ่านด่าน

## ลองเล่น

บนเครื่องนี้มีตัวเกม Windows รุ่นแก้บั๊กที่ `Logs/Room01CompanionFix_20261012/Windows/MysteryGame.exe` เปิดแล้วเลือกเริ่มเกมใหม่เพื่อเข้าห้องแรก ถ้าจะย้ายเครื่อง ต้องคัดลอกทั้งโฟลเดอร์ `Windows` ไม่ใช่เฉพาะไฟล์ `.exe` ตัวเกมนี้ยังไม่ได้ส่งขึ้น GitHub

1. ใช้ branch `codex/room01-companion` ใน Unity 2021.3.16f1 เปิด `Assets/Scenes/Room01.unity` แล้วกด Play / เริ่มเกม
2. เข้าใกล้ Alice แล้วใช้แผง **เพื่อนร่วมสำรวจ** ด้านขวาบน: **ตามมา**, **รอตรงนี้**, **ช่วยกัน**, **อยู่ด้วยกันนะ**
3. ลองเดินสำรวจพร้อม Alice เธอจะเคลื่อนไหวตามและหลบสิ่งกีดขวาง ไม่เทเลพอร์ต การสั่งให้รอระหว่างเดินตามหรือช่วยงานทำได้แม้เดินห่างออกมาแล้ว
4. ไปที่ **กล่องสองมือ** กลางห้องด้านล่าง กด **ช่วยกัน** Alice จะเดินไปจุดสีฟ้า ผู้เล่นยืนจุดสีทองให้ครบ **3 วินาที** หากเดินออกก่อน เวลาจะเริ่มใหม่
5. เมื่อสำเร็จ กล่องเปลี่ยนเป็นเปิด มีบทพูดตอบรับ ความสัมพันธ์ +3 และความทรงจำร่วมในสมุด **J** คุยกับ Alice อีกครั้งจะมีคำทักเกี่ยวกับสิ่งที่ทำด้วยกัน (เมื่อความสัมพันธ์มากกว่า 35)
6. ลองสำรวจภาพวาด โต๊ะ และเปิดลิ้นชักขณะ Alice อยู่ใกล้ จะมีปฏิกิริยาสั้น ๆ ตามผลการกระทำจริง ไม่ต้องเปิดบทสนทนาและไม่หยุดการเดิน

ไม่ต้องใส่ API key เพื่อเล่นระบบนี้ บทพูดสั้นและผลการกระทำกำหนดโดยเกม หากเปิดใช้ AI ตามปกติ ระบบจะส่งสถานะเพื่อนและความทรงจำที่เกมยืนยันไปประกอบบทสนทนา แต่ AI ไม่ใช่ผู้ตัดสินว่าช่วยงานสำเร็จหรือไม่

## จุดแก้หลังตรวจต้นแบบ

- สถานะกิจกรรมมี factId แยก `pending` / `completed` ตาม GameState ส่วนโหมดเดินตาม/รอ/ช่วยอ้างจากตัว NPC จริง AI ใช้ `{fact:factId}` บนบรรทัดแยก เกมเติมข้อความสถานะเอง ไม่ยอมรับ fact ของสถานะที่ยังไม่เกิด
- ตัวกรองปฏิเสธข้อความ AI ที่แต่งผลกิจกรรมด้วยชื่อ/ชื่อเรียกอื่นที่ตั้งไว้ และรูปประโยครายงานการกระทำ เช่น “ฉันเปิดให้แล้ว” ทั้งในแชทและ mini event โดยไม่เพิ่มสิทธิ์คำใบ้ ข้อความสังคม/ความรู้สึกยังเขียนตามบุคลิกได้
- รหัสผิดที่ใส่ครบในคีย์แพดส่งผลการลองจริงให้ Alice รับรู้ หน้าคีย์แพดยังเปิดอยู่ให้ลองใหม่ การใส่ไม่ครบหรือกดปิดไม่ถือว่าล้มเหลว
- สำรวจลิ้นชักที่เปิดแล้วไม่สร้างความทรงจำว่าผู้เล่นเปิดไม่สำเร็จ ส่วนการลองใช้วัตถุที่ยังติดเงื่อนไขยังนับเป็นความพยายามที่ไม่สำเร็จตามเดิม
- กดช่วยกิจกรรมเดิมซ้ำไม่ล้างความคืบหน้า ไม่ต่อเวลา และไม่ลืมว่าก่อนช่วยเคยเดินตาม เมื่อสลับงานยังจำการเดินตามเดิม แต่กดรอจะยกเลิกเจตนานี้

ตัวกรองภาษาเป็นมาตรการเสริม ไม่ใช่หลักฐานว่าโมเดลจริงจะไม่พูดผิดทุกสำนวน ต้องวัดการปฏิเสธและคุณภาพบทคุยกับ provider จริงแยกจากการทดสอบจำลอง

## ขอบเขตและกติกา

- กล่องสองมือเป็นกิจกรรมเสริม ไม่มีรหัส กุญแจ หรือเงื่อนไขใหม่สำหรับประตู เส้นทางเดิมยังเป็น ภาพวาด → โต๊ะ/โน้ต → ลิ้นชัก → กุญแจ → ประตู
- ไม่ต้องมีความสัมพันธ์สูงก่อนร่วมมือ ไม่เพิ่มระดับคำใบ้เพื่อแลกกับการช่วยงาน
- รางวัลกล่องและการให้กำลังใจ (+1, ลดคิดถึงบ้าน 10) ได้ครั้งเดียวต่อเซฟ กดซ้ำไม่สะสมคะแนน
- การเปิดบทสนทนา เมนู สมุด หรือหน้าต่างตั้งค่าจะพักการเคลื่อนไหวและเวลาช่วยงาน ไม่เด้งบทสนทนาขัดการเล่น
- ถ้าไปไม่ถึงหรือรอนานเกิน 45 วินาทีของเวลาเล่นจริง Alice จะยกเลิกงานโดยไม่ให้รางวัล สามารถชวนใหม่ได้
- เซฟเก็บผลสำเร็จ สมุด และความทรงจำ แต่ไม่เก็บตำแหน่ง/เส้นทางเดิน/งานที่ยังไม่เสร็จ โหลดเซฟแล้วต้องชวนใหม่ เริ่มเกมใหม่จึงเล่นกิจกรรมซ้ำได้
- ปฏิกิริยาการสำรวจแต่ละแบบเกิดครั้งเดียวต่อเซฟและต้องอยู่ใกล้กัน ข้อความที่ผู้เล่นหรือ AI พิมพ์ไม่ถือว่าได้สำรวจสำเร็จ
- ห้อง 02–03 ไม่เปิดระบบนี้เอง

## ให้เพื่อนต่อยอด

ข้อมูลอยู่ที่ `Assets/Data/Companions/Room01_Companion.asset` เชื่อมผ่านช่อง `companionScenario` ของ `RoomKnowledgeData`

สร้าง `Game/Companion Scenario` ใหม่เพื่อปรับ NPC, ขอบเขตเดิน, ระยะห่าง, ตำแหน่งสองฝ่าย, เวลาช่วยงาน, บทพูด และปฏิกิริยาตาม `interactionId` โดยไม่เขียนสคริปต์เฉพาะตัวละคร กิจกรรมใช้ conditions เดิมของ framework

เมื่อเพิ่มกิจกรรม ให้ตั้งชื่อ `title` และ `gameplayTerms` เป็นชื่อเรียกอื่นทั้งไทย/อังกฤษที่ AI อาจใช้ (เช่น กล่อง / box) ชื่อกิจกรรมจะถูกตรวจเสมอ ชื่ออื่นเหล่านี้จำกัดเฉพาะห้องและ NPC ที่เปิดใช้ scenario นี้ และต้องอ้างผ่าน fact ไม่ใช่แต่งข้อเท็จจริงเอง

หลังแก้ข้อมูลใช้เมนู **Mystery Game → Validate Content** และรัน `CompanionTests` / `Room01CompanionTests` ควรทดสอบเดินจริงอีกครั้งเมื่อย้ายเฟอร์นิเจอร์ เพราะข้อมูลตำแหน่งต้องอยู่ในพื้นที่เดินได้

นี่เป็นต้นแบบกลไกสองฝ่ายและภาพกล่อง 2D แบบเรียบง่าย ยังไม่ใช่ NPC ที่หยิบ/ใช้สิ่งของใดก็ได้ ไม่ได้เพิ่มชุดภาพเดินใหม่ และยังไม่รวมระบบปริศนาหลายขั้นหรือการทดลองกับ API จริง
