# AI Mystery Game Prototype

ต้นแบบเกม escape room แบบ 2D ที่ NPC สามารถส่งสัญญาณชวนคุยและเริ่ม mini event จากความต้องการ อารมณ์ หรือความขัดแย้งได้ บทสนทนามีข้อมูลสำรองในเกมเสมอ จึงเล่นได้แม้ไม่ใส่ API key

สถานะงาน ปัญหาที่ทราบ และลำดับงานสำหรับผู้รับช่วงต่ออยู่ที่ `docs/PROJECT_HANDOFF_TH.md`

## ทดลองเล่น

1. เปิดโฟลเดอร์นี้ด้วย Unity `2021.3.16f1`
2. เปิด Scene `Assets/Scenes/Room01.unity`
3. กด Play
4. เดินด้วย WASD หรือปุ่มลูกศร และกด E เพื่อสำรวจหรือคุย
5. เมื่อเปิดบทสนทนา สามารถพิมพ์ข้อความแล้วกด Enter หรือปุ่ม `ส่ง` ได้ทันที
6. กด `ตั้งค่า AI` มุมขวาบนหรือ F10 เพื่อตั้งค่า AI
7. ออกจากบทสนทนาด้วยปุ่ม `ปิด ×` หรือปุ่ม Escape

## ตั้งค่า AI

- **OpenAI**: เลือก OpenAI, เลือก/กรอก model, ใส่ API key แล้วกด APPLY
- **KKU IntelSphere**: เลือก KKU IntelSphere ระบบจะใส่ endpoint ให้อัตโนมัติ จากนั้นกรอก model name/ID ที่บัญชีใช้ได้และ API key แล้วกด APPLY
- **Custom**: ใช้กับบริการที่รองรับ OpenAI-compatible Chat Completions โดยกรอก endpoint, model และ key เอง

หลังบันทึกค่าให้กด `ทดสอบการเชื่อมต่อ` หาก key, model หรือ endpoint ใช้ไม่ได้ หน้าต่างจะแสดงข้อความจากผู้ให้บริการแทนการซ่อนข้อผิดพลาด

API key จะอยู่เฉพาะในหน่วยความจำระหว่างเปิดเกม ไม่ถูกเขียนลง Scene, PlayerPrefs หรือ Git ถ้าไม่ตั้งค่า AI เกมจะใช้บทสนทนาสำรองแทน

บทสนทนาที่ผู้เล่นพิมพ์เองจะใช้ AI ตอบตามบุคลิกและบริบทของ NPC พร้อมประเมินผลต่อความสัมพันธ์ หากยังไม่ได้ตั้ง API ระบบจะตอบด้วยบทสนทนาสำรองภายในเกมแทน

เมื่อกลับมาคุยกับ NPC อีกครั้ง บทเปิดจะเปลี่ยนตามความสัมพันธ์ ความทรงจำ และการเปลี่ยนแปลงของสถานะห้องนับจากการคุยครั้งก่อน

## ภาพตัวละคร

- ฉากใช้ห้อง 2D มุมมอง top-down และตัวละครในห้องใช้ภาพ chibi พร้อมการขยับเดินแบบ procedural
- ภาพเต็มจะแสดงเฉพาะตอนเปิดบทสนทนา และเด้งตามช่วงที่ตัวละครกำลังพูด
- เปลี่ยนภาพได้จาก Sprite ที่อ้างอิงใน Scene และ DialogueData
